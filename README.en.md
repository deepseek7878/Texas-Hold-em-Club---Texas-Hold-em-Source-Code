# Texas Hold'em Club Source Code

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [GitHub Pages](https://deepseek7878.github.io/texas-holdem-club/)

Texas Hold'em Club is a complete poker club source-code project for private rooms, club operation, unions, lobby games, real-time multiplayer tables and tournament events. It is suitable for Texas Hold'em apps, H5 games, Unity clients, C++ game servers, operation dashboards, room systems, chip systems, rankings and commercial poker-platform development.

The repository already covers online poker club features, private/public rooms, lobby, real-time gameplay, chat, tournaments, chips, admin DTOs and C++ game logic. This optimization package adds English and Traditional Chinese README files, GitHub Pages documentation, robots.txt, sitemap.xml, contribution, security and search-optimization files.

> Compliance note: Use this project only within lawful regions and lawful business scopes. Public deployments should follow local laws, age restrictions, payment compliance, platform rules and user-privacy requirements.

## Platform Features

| Module | Description | Value |
|---|---|---|
| Lobby | Room list, hot tables, rankings and announcements | Improve retention |
| Private/Public Rooms | 2-9 player tables, password rooms and blind settings | Club operation |
| Real-time Gameplay | Deal, bet, call, raise, fold and all-in | Complete poker flow |
| Hand Evaluation | Server-side hand ranking and settlement | Authoritative results |
| Side Pots | Main pot, side pots and split pots | Complex all-in support |
| Chat | Room chat, global chat, emoji and quick phrases | Social experience |
| Tournaments | Scheduled events, elimination, blind levels and rankings | Event operation |
| Chips | Virtual chips, daily rewards and transaction logs | Operation support |
| Club / Union | Agents, members, rooms and revenue statistics | Multi-level operation |
| Admin Dashboard | Users, games, rooms, logs and risk control | Business management |
